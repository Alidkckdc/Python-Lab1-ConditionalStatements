# Python-Lab1-ConditionalStatements
In this task we have to calculate the user's BMI and give the output of his bodytipe. BMI has a special formula and the formula is weight/(height*height). After all the progress we have have to find out user's bodytipe with his BMI. If it is under 18,5 he is underweight. If it is between 18,5 and 24,9 user is normalweight.
Between 25 and 29,9 is overwight and more than 29,9 is obese.
